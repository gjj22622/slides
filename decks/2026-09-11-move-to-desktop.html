把簡報工作搬到本機 Claude Desktop

照這份做完，本機就能自己做簡報、自己發佈、自己拿到公開網址。HP 那邊不用關。

先講一個好消息：不用裝 MCP

Claude Desktop 就是 Claude Code Desktop，同一個應用程式。裡面的 Code 分頁內建 Bash 與 PowerShell 工具，也能直接讀寫檔案，所以 pubslide 在上面跑得起來，不需要另外接檔案系統 MCP server。

CLI、Desktop、VS Code 擴充三者共用同一份 CLAUDE.md、skills 與設定，等於同一套環境的不同入口。

1哪些搬、哪些不搬

這件事不是整組搬家，是把「做簡報」這條線複製過去，「薇姐」留在原地。

東西動作為什麼
簡報製作與發佈
slides repo、pubslide、範本		 搬過去本機做、本機發，不用再連線到 HP
全域自動發佈規則
~/.claude/CLAUDE.md		 搬過去這個檔沒有版本控制，不會自己跟著走

她的記憶與名片庫

搬完之後長這樣

HP 繼續當 24 小時的機器：薇姐、排程、情資早報、人脈提醒照常跑。

本機 當工作台：做簡報、做報告、做原型，做完直接發佈拿網址。

兩邊共用同一個 GitHub repo，不會打架——發佈前程式會自動拉遠端，兩台發的東西都會出現在同一個首頁上。

2裝 Claude Desktop

如果已經裝好可以跳過這段。Windows 二選一：

winget install Anthropic.ClaudeCode
irm https://claude.ai/install.ps1 | iex

裝好打開，切到 Code 分頁，用你的 Claude 帳號登入。之後所有指令都可以直接叫它幫你跑，你不用自己開終端機。

3接上發佈管線

三行。可以自己在終端機跑，也可以整段貼給 Claude 叫它跑。

gh auth login
git clone https://github.com/gjj22622/slides.git $HOME\slides
powershell -ExecutionPolicy Bypass -File $HOME\slides\setup.ps1
gh auth login
git clone https://github.com/gjj22622/slides.git ~/slides
bash ~/slides/setup.sh

gh auth login 會問幾個問題：選 GitHub.com、HTTPS、用瀏覽器登入，帳號是 gjj22622。

安裝腳本會逐項檢查 Python、git、GitHub 登入、建立 pubslide 指令、確認能連上 repo，最後告訴你幾項通過、幾項要處理。有 ❌ 就照它說的補，補完再跑一次。

4把私密區密碼搬過去

只發公開簡報的話可以跳過這步。要用加密的私密區才需要。

方法 A：從 HP 複製（推薦，舊的私密簡報還打得開）

mkdir $HOME\.config\slides -Force
scp jacky@hp:~/.config/slides/password $HOME\.config\slides\password
mkdir -p ~/.config/slides
scp jacky@hp:~/.config/slides/password ~/.config/slides/password
chmod 600 ~/.config/slides/password

hp 換成你 Tailscale 上的主機名稱或 IP。也可以直接在 HP 上 cat ~/.config/slides/password 看一眼，手動輸入到新機器。

方法 B：設一組新的

pubslide --set-password '你的新密碼'

換密碼的代價：已經發佈的私密簡報是用舊密碼加密的，換了新密碼它們不會自動跟著換。要讓它們用新密碼，得把原稿重新發佈一次。原稿在 HP 的 ~/slides/private-src/，那個目錄刻意不進 repo。

5讓 Claude 知道要自動發佈

這步最容易漏。~/.claude/CLAUDE.md 沒有版本控制，不會跟著 repo 走。沒貼這段，新機器的 Claude 不知道你要它做完簡報就發佈。

$r = Get-Content "$HOME\slides\claude-rule.md" -Raw
$r.Substring($r.IndexOf("## HTML 簡報自動發佈規則")) | Add-Content "$HOME\.claude\CLAUDE.md"
sed -n '/^## HTML 簡報自動發佈規則/,$p' ~/slides/claude-rule.md >> ~/.claude/CLAUDE.md

規則的正本在 repo 裡的 claude-rule.md，以後改規則改那份，兩台機器都貼得到同一版。

6選配：讓 Claude 能自己檢查做出來的東西

裝了這個，Claude 做完簡報會自己用瀏覽器截圖檢查再交件，而不是憑推測說「做好了」。双云那份公司簡介封面糊掉、人物腳穿過雲，都是靠這個抓到的。

pip install playwright
playwright install chromium

約 150 MB。不裝也能用，只是交件前少一道自檢。

7驗收

照順序做完這五項，就算搬好了。

  1. pubslide --list 列得出兩份既有簡報
  2. 複製 ~/slides/decks/_template.html 改個標題，用 pubslide 發佈，拿得到網址
  3. 手機打開那條網址，看得到、翻得動
  4. 用 pubslide --unpublish 把測試那份撤掉
  5. 開一個新的 Claude 對話說「做一份三頁的測試簡報」，它應該做完自動發佈並附網址——沒有的話就是第 5 步的規則沒貼成功

8兩台機器並存要注意的

會自己處理好的

  • 發佈前會自動拉遠端，兩台發的簡報都會出現在同一個首頁。
  • 同時發佈撞在一起時會自動重試三次，不會互相覆蓋。
  • 私密簡報清單以加密檔存在 repo 裡，兩台看到的是同一份。

要你自己注意的

  • 私密簡報的原稿不會跟著走。private-src/ 裡是明文，刻意不進公開 repo。要在另一台改某份私密簡報，得自己把原稿複製過去。
  • 薇姐還是只在 HP 上。你在外面傳 .html 給她，她用的是 HP 上那份 repo，發佈結果兩邊共用，沒問題。
  • HP 別關機，關了薇姐就停了。
